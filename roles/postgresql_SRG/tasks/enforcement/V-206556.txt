STIG Compliance Artifact

Control ID: V-206556

Title:

Develop and maintain a list of DBMS database objects, configuration files, scripts, applications, and user environment files that may contain DBMS passwords. If passwords are present, ensure they are hashed using one-way salted hashing and protected by host system security.

⸻

1️⃣ Control Description Summary

The organization must:
	1.	Maintain an inventory of:
	•	DBMS database objects
	•	DBMS configuration files
	•	Associated scripts
	•	Applications (internal/external) accessing the DB
	•	User environment files
	2.	Document whether passwords exist in each location.
	3.	If passwords are present:
	•	Ensure they are hashed using one-way salted hashing functions
	•	Ensure hashes are protected via host OS security controls

⸻

2️⃣ Implementation Overview (PostgreSQL 15/16 Environment)

DBMS Platform: PostgreSQL 15/16
Operating System: RHEL 8.x
Authentication Method: SCRAM-SHA-256
Configuration Management: Ansible
Audit Logging: pgaudit enabled

⸻

4️⃣ Password Hashing Verification

PostgreSQL Password Encryption Setting

SHOW password_encryption;

Expected Output:

scram-sha-256

SCRAM provides:
	•	One-way hashing
	•	Per-user salt
	•	Iterative hashing
	•	FIPS-approved SHA-256

⸻

Verify No MD5 Usage

SELECT rolname FROM pg_authid WHERE rolpassword LIKE 'md5%';

Expected:
No rows returned.

5️⃣ Host System Security Protections

File Permission Controls

	•	Owner: postgres

	•	Config files: 600

OS Security Controls
	•	SELinux enforcing
	•	RHEL 8 STIG applied
	•	FIPS mode enabled

	•	Root login disabled

	•	Credential harvesting

Current implementation mitigates risk through:

	•	Centralized configuration management
	•	Regular automated scanning
