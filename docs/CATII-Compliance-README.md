## Architecture Context

This PostgreSQL 16 instance is deployed in an isolated, single-host environment with the following security-relevant characteristics:

- **Network exposure:** None — `listen_addresses = 'localhost'` only
- **Interactive users:** None — access restricted to `postgres` admin and application service accounts
- **Authentication:** SCRAM-SHA-256 enforced; `trust` authentication disabled
- **Audit:** pgaudit logging `ddl, role, write, read` with full `log_line_prefix` session context
- **SSL/TLS:** Not applicable — no network traversal between application and database host
- **Replication:** Disabled (`max_replication_slots = 0`, `max_wal_senders = 0`)
- **Session timeouts:** `idle_session_timeout = 15min`, `idle_in_transaction = 10min`, `statement = 30min`
- **Automation:** All controls enforced and validated on each `ansible-playbook` run via the `postgresql_SRG` role
