# PostgreSQL SRG – CAT II Compliance Status Overview

**System:** PostgreSQL 16
**Platform:** RHEL 9 (aarch64)
**Environment:** Isolated localhost deployment — no enterprise interactive users
**Automation:** Ansible (`postgresql_SRG` role, branch `feature/sonarqube-stig`)
**Assessment Date:** 2026-03-11

> All controls are assessed against a single-host, isolated PostgreSQL 16 instance that
> listens exclusively on `localhost`. No external network access, no enterprise interactive
> users. Access is restricted to the `postgres` administrative account and approved
> application service accounts. Ansible enforces and validates every applicable control
> automatically on each playbook run.
